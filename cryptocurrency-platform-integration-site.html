Brief

The company enables banks to offer bitcoin to their customers. As a part of their service they give the banks access to a range of resources including an integration site which shows them how their integration could look. This is supported by a range of prototypes which display the different features and API calls.

Solution

I developed a full set of screens and prototypes mocking up how these features would look in practice. These prototypes are used by hundreds of thousands of customers across the U.S. and allows the company's seemless integration with banks.

Overview

The result of this project is essentially a set of detailed screens and prototypes. There was a lot of research and support that went into this project which was key with the size of the user base.
